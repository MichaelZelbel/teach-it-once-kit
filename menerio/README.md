# menerio

Optional. Chapters 23 and 24 only. Everything else in the book works without this folder.

A memory home is a searchable copy of what your context files already know, reachable from a
phone and from any AI tool. It is a copy, never a move: your folder stays the original.

| File | What it is for |
|---|---|
| `folder-to-memory.md` | Chapter 23. The prompt that turns your folder into importable statements, what the import really costs, and the three things it does not do. |
| `mcp-connection.md` | Chapter 24. Making the token, and plugging the same memory into more than one tool. |
| `ai-memory-transport.md` | The older route: pulling out what a chat product remembers about you. Kept because it still helps if your files are thin. |
| `interview-transfer.md` | Filling a memory home by being interviewed, when you would rather talk than paste. |

## The one number worth knowing before you start

A new free account gets **500 AI credits**. Importing a full context folder (64 statements) cost
**20** of them, measured on a brand new free account on 2026-07-26. That is about twenty-five full
imports, and the allowance refills monthly.

Accounts created before the free allowance existed can still show `0 / 0`, because it was not
applied backwards. If yours shows zero and the import fails, that is why.
