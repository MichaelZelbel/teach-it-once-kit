# An AI of Your Own — Companion Kit

The reader kit for the book **An AI of Your Own: Build a personal AI that knows you, works your way, and runs without you** by Michael Zelbel.

Everything the book asks you to copy, paste, fill in, or print lives here. You never have to type a template from a page.

## How to get it

No terminal needed: click the green **Code** button on GitHub and choose **Download ZIP**, then unpack it anywhere.

Once you reach Part VI of the book (the file-based system), you will clone it instead:

```
git clone https://github.com/MichaelZelbel/an-ai-of-your-own-kit.git
```

## What is where

- `context/` — Part II assets: the about-you template, the people brief, the voice extraction prompt, the capture and spring-clean checklists.
- `skills/` — Part III assets: the five starter skill recipes, the craft-skill interview, the skill library template, practice texts.
- `procedures/` — Part IV assets: morning brief, weekly review, watchdog, the procedure register, the red lines.
- `living/` — Part V assets: the two-questions card, the privacy audit checklist, the printable one-month plan.
- `starter-hub/` — Part VI: the folder that becomes your own file-based system. You copy this whole folder and it is your hub.
- `menerio/` — Part VI: prompts and guides for moving your context into Menerio (memory transport, the interview method, GitHub sync, MCP connection).
- `server/` — Part VI: scripts and guides for giving your system an always-on home.
- `swap/` — Part VI: config examples for running the same system on a different vendor's tool and model.

The full chapter-by-chapter map is in `docs/CHAPTERS.md`.

## Status

The book is in production. Folders marked **building** in `docs/CHAPTERS.md` fill up as their chapters are verified and written. Nothing lands here before it has been run live.
