# The One-Month Plan (Chapter 24)

Thirty days, twenty minutes a day. Print this, put it where you make
coffee, cross days off with a pen.

**The four rules:** 20 minutes is a ceiling (stop when the timer ends);
buffer days are legal; never build angry (do a maintenance day: read
yesterday's output, make one correction); one tool for the whole month.
**If you fall off:** do not restart, resume. There is no streak.

## Week 1: it learns you

- [ ] Day 1: About-you page: **More about you**, nickname, occupation
      (Ch 5). Test: "help me plan my week" in a fresh chat.
- [ ] Day 2: People pages for your core cast (Ch 6).
- [ ] Day 3: Projects and priorities (Ch 7).
- [ ] Day 4: Voice: extraction from real messages, style field, never
      list (Ch 8).
- [ ] Day 5: Capture habit on; save three real facts today (Ch 9).
- [ ] Day 6: Test day: rerun before/after questions, fix the worst
      answer at its source.
- [ ] Day 7: Buffer.

## Week 2: it works your way

- [ ] Day 8: Build "Summarize for me" (Ch 11). Save, not the X.
- [ ] Day 9: Install "Answer email my way" + "Plan my day" (Ch 12).
- [ ] Day 10: Install "Prep me for a meeting" + "Draft my update"
      (Ch 12).
- [ ] Day 11: Craft interview; pick your three craft skills (Ch 13).
- [ ] Day 12: Build craft skill one.
- [ ] Day 13: Build craft skills two and three.
- [ ] Day 14: Skill library doc, master copies of all recipes (Ch 14);
      stranger-test your favorite (Ch 15).

## Week 3: it works without you

- [ ] Day 15: Fire a five-minute disposable scheduled task, watch it
      run, delete it (Ch 16, 18).
- [ ] Day 16: Build the morning brief (Ch 17).
- [ ] Day 17: Read the first brief; make exactly one correction.
- [ ] Day 18: Schedule the weekly review for Monday (Ch 18).
- [ ] Day 19: First watchdog, with receipt line and quiet line (Ch 19).
- [ ] Day 20: Write the register; pause/resume drill once (Ch 20).
- [ ] Day 21: Install the red lines; fire both grenades in a throwaway
      project (Ch 21).

## Week 4: you trust it

- [ ] Day 22: Two-questions habit, used once on a real answer (Ch 22).
- [ ] Day 23: Five-minute privacy audit + training switch (Ch 23).
- [ ] Day 24: Corrections day: twice-made corrections go into recipes
      (Ch 15 rule). Library first.
- [ ] Day 25: Improve one procedure or add a second watchdog.
- [ ] Day 26: One more craft skill, or pause what you ignored three
      times (Ch 20 firing rule).
- [ ] Day 27: Buffer.
- [ ] Day 28: Memory spring-clean (Ch 10).
- [ ] Day 29: Cold run: lean on the system all day; note every gap.
- [ ] Day 30: Review: register, library, about-you page. Strike, keep,
      and write the one line: what this system should learn next.
